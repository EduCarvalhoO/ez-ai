# Política de segurança

## Versões suportadas

O projeto está antes da versão 1.0. Só a branch `main` recebe correções de segurança.

## Como reportar uma vulnerabilidade

Não abra issue pública. Use o reporte privado do GitHub:
https://github.com/EduCarvalhoO/ez-ai/security/advisories/new

Inclua o que for possível: versão ou commit afetado, passos para reproduzir, impacto esperado e, se houver, uma sugestão de correção.

## O que esperar

- Confirmação de recebimento em até 7 dias.
- Avaliação e plano de correção combinados no próprio aviso privado.
- Divulgação pública só depois da correção publicada, com crédito a quem reportou, se desejar.

## Escopo

Vale para o código deste repositório, seus workflows de CI e as dependências que ele fixa. Problemas em ferramentas de terceiros (Claude Code, GitHub Copilot, npm) devem ser reportados aos respectivos mantenedores.
