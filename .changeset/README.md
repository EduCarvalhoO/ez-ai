# Changesets

Pasta do [`@changesets/cli`](https://changesets.dev): cada arquivo `.md` aqui descreve uma mudança e o tipo de versão (patch, minor, major) que ela pede. Crie um com `npx changeset add` (ou `npx changeset add --empty` para mudança sem release) e confira com `npx changeset status`. Configuração em `config.json`.
